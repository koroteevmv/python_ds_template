# python_ds_template
Шаблон репозитория Python для проекта по анализу данных

## Использование

1. Сделайте форк данного репозитория
1. Склонируйте этот репозиторий на локальный компьютер
1. Переименуйте проект в файлах `pyproject.toml` и `src/setup.py` (опционально)
1. Выполните команду `uv sync`
1. Запустите Jupyter командой `uv run jupyter lab`

## Структура репозитория

```
|- data/                        # папка для хранения всех датасетов для обработки
   |- raw/                      # исходные датасеты (неизменные)
   |- processed/                # промежуточные версии обработанных данных
   |- cleaned/                  # версии датасетов, от которых зависят модели
|- docs/                        # документация к проекту
|- models/                      # здесь храним сериализованные модели и веса
|- notebooks/                   # здесь лежат нумерованные ноутбуки для экспериментов
   |- prototype-notebook.ipynb  # шаблон ноутбука
   |- archive/                  # папка для более ненужных ноутбуков
   |- figures/                  # папка для картинок в ноутбуках
|- references/                  # 
|- reports/                     # 
   |- figures/                  # 
|- src/                         # воспроизводимый код как отрефакторенный артефакт
   |- module/                   # пакет для импорта в ноутбуки и скрипты
	  |- __init__.py            # пустой служебный файл для импортов
	  |- config.py              # глобальные настройки приложения
	  |- utils.py               # вспомогательные функции
   |- setup.py                  # инструкции для сборки приложения как библиотеки
|- scripts/                     # кастомные скрипты
   |- archive/                  # ненужные скрипты
|- main.py                      # главная точка входа в программу
|- .gitignore                   # файл для правильной индексации репозитория
|- LICENSE                      # лицензия, под которой распространяется код
|- README.md                    # измените данный файл для общего описания проекта
|- pyproject.toml               # список зависимостей и служебная информация uv
```
